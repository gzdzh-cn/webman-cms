# webman-cms 1.0.9

This tag is the reproducible source snapshot for the 1.0.9 release. It contains the CMS, locked Composer dependencies, system assets and their locked build inputs.

Use the assets attached to the GitHub Release for upgrades. These are upgrade packages for existing installations, not new-site installers. Site credentials, deployment YAML, themes, uploads, generated HTML, installation state and business database records are excluded.

See [release notes](docs/release-1.0.9.md) and [online upgrade documentation](docs/online-upgrade.md).
