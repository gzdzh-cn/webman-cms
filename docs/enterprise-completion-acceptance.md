## 本批实现

- 栏目与文档权限按角色的「栏目范围＋全部/本人归属」成对计算，并与功能、语言权限同时约束。列表、直接读取、编辑、删除、移动、复制、预览及关联选择共用范围服务。角色页复用旧更新身份，不新增权限节点或改已有角色字符串。
- 富文本来源以表、主键、字段、内容 SHA 和修订持久化；raw/encoded/unknown 明确区分。未知正文实际编辑前须双预览确认，标题修改不顺带重编码；正文与来源同事务保存。同步、复制及安装基线接入同一来源规则，不批量重写历史内容。
- 文档批量审核/属性、退回原因、重新提交及同语言同模型复制；复制先预检、绑定指纹并保存真实新 ID 映射。栏目批建、TAG 批量/关联、搜索词批量与配置、留言/搜索 CSV 导出接入原权限。
- 城市配置使用系统主语言；城市与多语言双向互斥并共享锁。历史 cn 配置只读预演，冲突拒绝覆盖。设备 m/mobile 归一，双模板模式采用相同源码写入边界。
- robots 固定路径编辑、SHA 冲突拒绝和前版本恢复；图片水印/缩略图配置接入新上传和派生图片；原文件不批量重处理。
- 项目私有数据库备份：签名清单、分卷校验、差异预检、维护门禁、暂存与前镜像、原子发布、中断恢复及只读回退预演。首版仅支持有界的本项目 InnoDB 备份格式，不接受任意上传 SQL。
- 修复共享窗口接入 detached DOM 时窗口不出现的问题；字段纠正后清除对应错误标记。自研 JS 源码、压缩产物、清单及恢复包成组更新。

实现入口与边界详见 `htmltext-and-archive-workflows.md`、`enterprise-management-tools.md`、`enterprise-capability-matrix.md`。安装规则和进度页保持；未重装开发站。
