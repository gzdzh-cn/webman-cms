## 使用

旧版后台手动检查更新并执行升级，升级完成后刷新一次后台即可加载新交互。1.0.12 默认 Gitee，只显示“新版本”标记；超管可在弹窗选择 Gitee / GitHub / 自定义。自定义请求地址从 CRM 对应 App 的“复制接入地址”获取，访问密码由管理员私下管理；读取密码和发布认证相互独立。
