# 固定实体目录

2026-11-11 按最新要求取消自定义实体目录。路径适配由 `app/cms/Paths.php` 的固定目录表维护，业务代码继续通过 Paths 读写；历史 URL 的兼容适配保留。

源码版基准为源码入口目录，二进制基准为可执行文件所在目录，与工作目录无关：

| 内容 | 固定位置 |
| --- | --- |
| 私有状态 | config |
| 系统公开资源 | public/admin-assets |
| 官网主题 | template |
| 上传 | uploads |
| 生成 HTML | public/html |
| 源码安装资料 | install 或既有可信封存记录指定目录 |
| 日志和运行文件 | runtime |

YAML 不再接受 paths 区段，遗留区段明确提示删除；原 CMS_SITE_ROOT 和目录环境变量不再参与目录选择。运行站当前配置原本没有 paths 区段，各实体均在默认位置，本批未迁移文件或改写私有配置。

内置 public/template 仍整根优先，uploads、public/html、runtime 始终外置。YAML/.env 的文件选择、环境变量覆盖其他部署字段，以及 build 输出和构建运行时目录配置保持其专用规则。cms:paths --check 继续检查固定目录。
