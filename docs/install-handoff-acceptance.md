## 实现范围

- 安装页显示转圈、“正在安装，请勿关闭页面”与真实阶段进度，提交期间禁用重复操作；支持读屏状态提示、减少动态效果和手机布局。
- 数据库、环境配置、本地完成记录和安装锁成功后，`InstallerHandoff` 安排脱离 HTTP worker 的固定重启命令。子进程关闭继承的监听流，再由独立执行器运行当前 PHP 的 `webman restart -d`；清除旧数据库环境，保留实例监听和 worker 参数。
- 任务记录位于私有 `config/cms-install-handoff.json`，使用互斥及原子保存，不依赖 runtime。核验当前项目主进程、替换后的 master、HTTP worker 父进程、新环境和后台数据库站点签名后，才能进入 ready。
- 成功页停留，服务 ready 后由用户点击“进入后台”。POST 兑换要求原安装会话和 CSRF，重新读取本次管理员，核验状态、密码哈希指纹与站点；共用普通登录的会话建立逻辑，更新登录时间、角色及 session ID，持久化成功后消费资格。
- 资格 ready 后最多 10 分钟且安装完成后最多 30 分钟；不保存明文密码、不经 URL 传递凭据。响应丢失或完成页刷新可在同一已登录会话恢复；退出后不能重放。
- 环境或锁保存失败不重启，只补安装收尾；封存单独失败保留提醒并允许重启。超时提供重新检查，自动失败后提供重试及手动命令，不重新导入。CLI 无运行实例时不主动启动，无浏览器 owner 不发放可兑换资格。
