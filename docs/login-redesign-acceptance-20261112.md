# 登录页设计与后台加载调整验收

## 范围与实现

本批仅重做未登录页面，登录后后台外观保持原样。登录页浏览器标题为“内容管理 · 登录”，品牌为“内容管理”，不再读取网站名称和后台 logo 配置；已登录后台继续使用网站名称。页面为浅蓝白色双栏，包含本地 CSS 内容工作区插图，850px以下只显示登录卡片，无外部字体、CDN及图片依赖。保留用户名、密码和验证码的原接口，增加关联标签及自动填充语义，保留键盘刷新验证码、失败输入保留、防重复提交、15秒登录超时和成功轻提示自动跳转。

登录页不再加载Pear入口、主题模块及Pear按钮CSS，实际公开依赖为3份CSS、2份JS，另有一次初始验证码请求；Layui form/layer仍提供表单与加载反馈。初始验证码由HTML直接请求，认证及会话存储未调整。

后台原先在界面模块加载完毕后才请求配置和权限菜单；现在在已认证HTML头部发起两个no-store请求，与样式及界面模块加载重叠。导航等待语言上下文后复用这批结果，不写本地持久缓存，失败由原重试界面接管；请求含15秒超时。移除未使用的pearDrawer初始化依赖，内存菜单的500毫秒等待缩为一次事件循环，保证实例赋值后才调用done；CMS加载遮罩固定保留时间归零，保留淡出动画。
