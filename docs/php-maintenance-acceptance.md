- 增加PHP `cms:deployment --check --json` 综合预检，汇总配置、路径权限、运行时和资源检查；不连数据库、不启动服务、不占用8793。旧固定端口自动演练/清理入口退役，不接管既有保留环境。已维护的兼容适配器不通过历史首次导入脚本重建。
