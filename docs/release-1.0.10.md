# webman-cms 1.0.10

- 升级中心切换至 Gitee 正式发行版和官方附件下载，改善国内服务器访问 GitHub Release 附件时超时的问题。
- 检查缓存按来源隔离；保留固定仓库、正式版本、包大小、SHA-256、平台及受管文件校验，下载失败显示具体阶段和错误类别。
- 发布工具默认支持 Gitee 预览上传、完整校验后显式正式发布，GitHub 通过 `--provider github` 镜像发布同批升级包。
- 包含近期后台统一紧凑布局、保存反馈与滚动恢复、文章发布时间保存修复。

旧版已编译二进制需要正常部署本版一次，之后通过后台从 Gitee 获取更新。标准二进制只内嵌系统资源；站点配置、主题、上传、生成 HTML 和数据库资料不进入包。源码运行包包含锁定依赖，服务器无需运行 Composer。
