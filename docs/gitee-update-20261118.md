## 故障证据

2026-11-18，A 服务器 3100 的原进程仍运行 1.0.8，持久化升级任务 current 为空。原检查缓存记录 GitHub 检查失败；原程序自身再次检查时返回 cURL 28：12 秒内只下载到 850,887 / 1,346,419 字节。故障发生在启动前重新检查，尚未进入任务下载、停服或文件替换阶段。现场 Gitee 公开 API 约 0.23 秒返回，公开测试附件 364,940 字节约 1.48 秒完整下载。

## 实现

默认固定 Gitee 仓库 gzdzh/webman-cms；最多检查十页正式发行版，按 CMS 版本比较，不依赖最后编辑时间。附件从独立 attach_files 接口读取，必须唯一；下载地址由服务端发布与附件身份构造。只允许 gitee.com 与 foruda.gitee.com 的 HTTPS 下载及重定向。GitHub 发布器与已有任务兼容仍保留，新的检查缓存、发布身份均包含 Gitee 来源。

Gitee 发布使用预览版作为准备阶段，finalize 校验全部资产后才正式发布。源码、Darwin ARM64 和 Linux x86_64 包从项目外同一安全快照构建。没有覆盖 v1.0.9 的标签或资产。
