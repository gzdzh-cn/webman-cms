# webman-cms 1.0.9

## 更新内容

- 统一后台紧凑布局：页面和面板间距 12px、控件间距 8px、标签页和按钮尺寸一致，左侧菜单收窄至 160px。
- 优化管理员、留言、素材库查询区，以及模板管理、个人资料、栏目和模型字段页面，减少多余留白和控件错位。
- 保存开始后立即显示“正在保存…”及工作区等待蒙版，防止重复提交；成功提示 0.5 秒、错误提示 1 秒，详细字段错误保留在页面。
- 修复基本设置保存后无法滚动的问题，结果提示使用不抢占模态焦点的浮层；保留输入、滚动位置及未保存提醒。
- 后台默认名称统一为“后台管理”，网站名称继续用于网站自身配置。
- 保留文章发布时间规范化、列表筛选分页、多语言，以及源码和标准二进制在线升级能力。

## 升级说明

- 从已具备在线升级能力的 1.0.7 / 1.0.8 后台检查更新，由超级管理员执行升级。
- 源码升级包包含锁定依赖；标准二进制按平台及系统资源内嵌方式匹配，运行服务器无需 Composer 或系统 PHP。
- 升级包不包含站点配置、凭据、主题、上传、生成 HTML、安装记录或数据库业务数据。
- 内嵌站点配置或主题的定制二进制需要专用升级包；systemd 部署使用维护窗口升级。
- 请在升级前保存正在编辑的内容，升级切换期间服务会短暂停止。
