# 后台页面与交互规范

本轮沿用现有紧凑白卡、蓝色主操作和 Layui／原生控件，不增加另一套后台框架。参考 EyouCMS 的业务命名和任务顺序，不照搬其旧窗口尺寸，不新增会员和交易功能。

## 页面和窗口

- 栏目、文章／单页、广告、管理员、复杂模型字段、表单配置和邮件正文等复杂编辑使用当前内容区整页，左上角返回，保存操作保持可见。
- 简单名称、分组、位置及开关编辑使用720px标准弹窗；素材、栏目、文档选择及差异比较使用1040px大窗口；影响确认使用520px窗口。
- 宽度始终受视口约束，高度不超过85vh。手机编辑与选择改为单列近全屏，确认窗口保留边距，滚动区域不能隐藏最后一个字段或保存按钮。
- 标题写明业务对象，如“新增广告”“编辑友情链接”。操作使用“保存／取消／返回列表”；查询区保留“查询／重置”，编辑区不提供无解释的重置操作。
- 编辑窗口点击蒙版不关闭；Esc、关闭、返回和语言切换均检查未保存内容。素材选择器保留现有组件的必要上下文，不创建无限嵌套的小窗口。

## 表格与表单

默认列、顺序、字段名称及控件由业务展示配置决定，不能按数据库顺序截取前八列。数据库字段键和存储值不改。

- ID仅在识别业务对象时显示；管理员、分组、位置、栏目和文档关联优先显示可读名称。
- 状态显示“启用／停用”等业务文本，日期显示可读时间，0按字段含义显示“未设置／不限”。未知历史枚举显示原值并标记，不自动重置。
- 图片提供缩略图和选择，文件显示名称／类型／大小，长文本及地址可查看或复制；数据库计算值、删除标志和语言归属不作为普通文本输入。
- 整页保存成功返回来源列表并恢复语言、筛选、分页和树展开状态；弹窗保存成功关闭并刷新列表。角色与语言范围的独立未保存保护继续保留。

## 状态、失败与权限

- 查询和筛选不算未保存编辑；编辑输入离开时询问“继续编辑／放弃修改”。
- 保存期间防重复提交；失败保留输入、停止动画并恢复按钮。字段错误显示在字段旁，网络或登录失效错误显示在当前表单内。
- 明确加载中、无数据、读取失败和无权限。长任务仅显示真实阶段及成功／失败／跳过数量，不合并为虚假全部成功。
- 页面和按钮只反映现有权限，服务端继续校验原controller key、动作和真实语言；新的展示参数不能绕过记录语言及写权限。
- 原主题、上传、生成HTML、安装进度、账号密码和授权数据不随UI改造调整。多语言包维持离线来源，不恢复官方联网同步。

## 资源与交付

自研源码、发布产物、资源清单及恢复包同步成组维护；Node依赖和构建缓存位于项目外，运行无需Node。实施及验收以[本轮记录](backend-ui-acceptance.md)为准，源码检查、夹具、实际HTTP和浏览器证据分别记录，不相互替代。

## 城市分站与语言同步补充（2026-11-08）

城市分站列表和设置分开页签，新增和编辑为整页；搜索显示匹配地区及其上级，展开状态和搜索按编辑语言保存。固定保存区，成功返回筛选列表，错误字段保留输入并恢复按钮。同步预检和记录是picker任务窗口，不标记为page editor。危险主操作使用白字红底。顶栏语言菜单在保存或上传期间拒绝切换。


## 顶部工具与模式反馈（2026-11-09）

语言入口支持鼠标悬停、点击和方向键，按授权列出当前可编辑语言；末项“编辑语言”进入语言列表，多语言关闭时仍可进入维护。官网预览只保留图标和可访问名称。管理员下拉集中个人资料、刷新、全屏、外观、重启和退出，手机下隐藏姓名以保留空间。

网站模式在保存时显示确认窗口，切入或切出 Redis 明确提示重新登录；执行期间显示实际验证进度，成功显示完成状态。Redis 验证失败展示2秒红色提示，同时保留网站模式旁的红字、自动定位并保留未保存输入。弹窗提供进入动画、模糊背景、执行旋转和成功反馈，系统减少动态效果设置受尊重。

“重启程序”仅超级管理员可用；确认后显示真实阶段，连接暂断时继续等待，新主进程响应已认证状态请求后才显示成功并刷新。保存或上传在途拒绝重启，有未保存编辑时明确提示影响；失败恢复按钮并保留错误。服务端执行固定项目重启命令，不接受命令或目录参数；不支持相关进程函数的环境显示明确错误，需服务器管理员操作。真实浏览器验收见[本批记录](admin-topbar-acceptance.md)。
