# 后台页面与交互规范

本轮沿用现有紧凑白卡、蓝色主操作和 Layui／原生控件，不增加另一套后台框架。参考 EyouCMS 的业务命名和任务顺序，不照搬其旧窗口尺寸，不新增会员和交易功能。

## 统一尺寸与保存状态（2026-11-17）

- 共享变量在 `cms-ui.css` 管理：页面、面板、区块间距12px，控件间距8px；普通控件及按钮32px／13px，表格操作26px／13px，标签36px／13px并使用蓝色下划线选中态。嵌套面板不重复叠加内边距；窄屏查询自然换行，日期范围保持一组。
- 展开侧栏160px；保留折叠与手机抽屉。后台标识固定“后台管理”，网站名称仍由基本设置维护并用于网站自身。
- 普通写入在验证通过后立即调用 `const pending=CmsUI.beginSave(form)`；按钮显示“正在保存…”，工作区等待蒙版阻止重复操作。每次请求持有自己的句柄，结束时 `pending.close()`，随后只显示一次 `success/failure`；`finally` 再清理可重复调用。新代码优先使用独立句柄，传统 `setBusy` 保持兼容。
- 请求失败、超时、表单移除与页面销毁必须清理；普通保存60秒超时，已有进度任务按自身规则处理。弹窗滚动锁由当前文档内仍打开的整页编辑窗口决定；关闭子窗口不能解除外层窗口的锁。焦点恢复使用 `preventScroll`。
- 成功500ms，错误1000ms，包含进入动画；字段错误与详细原因保留在表单中。Layui校验继续使用原规则，提示转入共享反馈。已有模式切换确认与真实进度不改为短提示。基本设置直接采用保存响应中的规范化数据，保留滚动位置和凭据脱敏，不重复读取整个表单。

结果短提示使用不占用模态焦点的浮层：不得调用 `showModal()`，不得在关闭时聚焦父工作区的 iframe。支持时使用手动 Popover 放在顶层，保留轻背景和原有动画；已有编辑窗口打开时将提示归属该窗口，不解除它的滚动锁。基本设置在恢复按钮后用 `preventScroll` 恢复提交按钮焦点，使键盘事件返回原页面。详见[保存滚动修复](backend-scroll-fix-20261117.md)。

## 页面和窗口

- 栏目、文章／单页、广告、管理员、复杂模型字段、表单配置和邮件正文等复杂编辑使用当前内容区整页，左上角返回，保存操作保持可见。
- 简单名称、分组、位置及开关编辑使用720px标准弹窗；素材、栏目、文档选择及差异比较使用1040px大窗口；影响确认使用520px窗口。
- 宽度始终受视口约束，高度不超过85vh。手机编辑与选择改为单列近全屏，确认窗口保留边距，滚动区域不能隐藏最后一个字段或保存按钮。
- 标题写明业务对象，如“新增广告”“编辑友情链接”。操作使用“保存／取消／返回列表”；查询区保留“查询／重置”。设置与编辑页的“重置”放在保存按钮旁，恢复最近读取或保存的内容，有修改时确认；不使用原生表单 reset，不提供重复的刷新或还原按钮。列表与任务进度的刷新保留。
- 编辑窗口点击蒙版不关闭；Esc、关闭、返回和语言切换均检查未保存内容。素材选择器保留现有组件的必要上下文，不创建无限嵌套的小窗口。

插件市场及后续适配插件沿用上述规范：列表复用工作区白卡、查询／重置、状态筛选、表格及行内操作，不另设配色或卡片体系。简单插件配置使用720px标准弹窗，连接、凭据和存储策略分组；标题及底部操作栏固定，仅正文滚动。手机字段单列，保存、重置、取消始终可达。重置恢复最近读取或保存的配置并确认未保存修改；保存失败保留输入，关闭和成功保存后恢复列表焦点。凭据不回显，留空保留，清除使用独立操作。

## 表格与表单

默认列、顺序、字段名称及控件由业务展示配置决定，不能按数据库顺序截取前八列。数据库字段键和存储值不改。

- ID仅在识别业务对象时显示；管理员、分组、位置、栏目和文档关联优先显示可读名称。
- 状态显示“启用／停用”等业务文本，日期显示可读时间，0按字段含义显示“未设置／不限”。未知历史枚举显示原值并标记，不自动重置。
- 图片提供缩略图和选择，文件显示名称／类型／大小，长文本及地址可查看或复制；数据库计算值、删除标志和语言归属不作为普通文本输入。
- 整页保存成功返回来源列表并恢复语言、筛选、分页和树展开状态；弹窗保存成功关闭并刷新列表。角色与语言范围的独立未保存保护继续保留。

## 状态、失败与权限

- 查询和筛选不算未保存编辑；编辑输入离开时询问“继续编辑／放弃修改”。
- 保存期间防重复提交；失败保留输入、停止动画并恢复按钮。字段错误显示在字段旁，网络或登录失效错误保留在当前表单内，同时显示居中的动画弹窗；保存成功也使用同一弹窗，成功500ms、错误1000ms自动关闭（含动画时间）。页面内字段错误和未保存输入继续保留。
- 明确加载中、无数据、读取失败和无权限。长任务仅显示真实阶段及成功／失败／跳过数量，不合并为虚假全部成功。
- 页面和按钮只反映现有权限，服务端继续校验原controller key、动作和真实语言；新的展示参数不能绕过记录语言及写权限。
- 原主题、上传、生成HTML、安装进度、账号密码和授权数据不随UI改造调整。多语言包维持离线来源，不恢复官方联网同步。

## 资源与交付

自研源码、发布产物、资源清单及恢复包同步成组维护；项目维护统一使用PHP，不依赖Node或Python。实施及验收以[本轮记录](backend-ui-acceptance.md)为准，源码检查、夹具、实际HTTP和浏览器证据分别记录，不相互替代。

## 城市分站与语言同步补充（2026-11-08）

城市分站列表和设置分开页签，新增和编辑为整页；搜索显示匹配地区及其上级，展开状态和搜索按编辑语言保存。固定保存区，成功返回筛选列表，错误字段保留输入并恢复按钮。同步预检和记录是picker任务窗口，不标记为page editor。危险主操作使用白字红底。顶栏语言菜单在保存或上传期间拒绝切换。


## 顶部工具与模式反馈（2026-11-09）

语言入口支持鼠标悬停、点击和方向键，按授权列出当前可编辑语言；末项“编辑语言”进入语言列表，多语言关闭时仍可进入维护。官网预览只保留图标和可访问名称。管理员下拉集中个人资料、刷新、全屏、外观、重启和退出，手机下隐藏姓名以保留空间。

网站模式在保存时显示确认窗口，切入或切出 Redis 明确提示重新登录；执行期间显示实际验证进度，成功显示完成状态。Redis 验证失败展示1000ms红色提示，同时保留网站模式旁的红字、自动定位并保留未保存输入。弹窗提供进入动画、模糊背景、执行旋转和成功反馈，系统减少动态效果设置受尊重。

“重启程序”仅超级管理员可用；确认后显示真实阶段，连接暂断时继续等待，新主进程响应已认证状态请求后才显示成功并刷新。保存或上传在途拒绝重启，有未保存编辑时明确提示影响；失败恢复按钮并保留错误。服务端执行固定项目重启命令，不接受命令或目录参数；不支持相关进程函数的环境显示明确错误，需服务器管理员操作。真实浏览器验收见[本批记录](admin-topbar-acceptance.md)。

## 后台入口与 Sitemap（2026-11-11）

后台入口及API统一使用 `/web-admin`，保留原控制器权限身份。旧 `/app/admin` 操作入口返回404，已登记的旧静态资源与头像地址继续兼容；旧菜单和默认配置在读取时投影成新URL，无需改写业务数据库。

Sitemap 的 XML、TXT、HTML 每项独占一行，各自提供生成按钮；只生成所选格式，保留其他地图记录。生成使用已保存的配置，未保存编辑继续保留；底部仅保留保存、重置及清理操作。

保存结果使用 `CmsUI.success/failure/persist`，弹窗由同源工作区承载，关闭编辑窗口不会遮住结果；整页返回及传统回调等待提示完成。Redis模式切换沿用其确认与进度窗口，失败使用同一结果弹窗并保留字段诊断。查询、上传和任务轮询不自动触发保存弹窗。

登录及其他未认证后台页面使用公共反馈时，也必须加载 `cms-ui` 样式和脚本；资源引导独立于管理员与语言状态，匿名页面不注入私有语言上下文。验收需实际提交匿名失败请求，确认提示出现、加载动画结束且按钮恢复，不能只检查已登录编辑页。

登录结果使用无蒙层的轻提示，不使用保存结果弹窗。成功后先清除登录表单的未保存标记，短暂提示后自动进入后台，跳转前再次清理以避免浏览器离开确认；失败保留输入并恢复按钮。

登录验证码必须由HTML中的图片src直接加载，不等待Layui或后台框架初始化；点击和键盘刷新使用原生事件，登录失败后才另行刷新，避免页面首次加载时重复请求。登录页仅加载表单、弹层及必要样式，不引入后台菜单、标签页或整套Pear样式；验证码响应禁止缓存，仍通过原会话验证，不能通过性能优化绕开认证。

登录轻提示与业务保存结果统一使用白色卡片、细灰边框、柔和阴影和小尺寸状态图标；成功为绿、失败为红、警告为琥珀色，底部细进度条表示自动关闭时间。保存结果采用图标与文字横排的紧凑居中卡片、轻蒙层，成功500ms、错误1000ms自动关闭（含动画时间）；登录提示位于顶部，不阻挡页面。长信息换行，窄屏保留边距，文字通过textContent输出；系统减少动态效果时关闭动画。编辑页关闭后的结果仍由同源工作区承载，原有跳转、回调与字段诊断规则保持。

## 登录页与启动加载（2026-11-12）

登录页的品牌与浏览器标题固定使用“内容管理”，不查询网站名称或自定义后台标识；登录后的后台名称标识与浏览器主标题统一为“后台管理”，独立于网站名称。登录页采用浅蓝白色双栏布局，窄屏只保留登录卡片，不加载外部字体、图片或整套 Pear 框架。装饰图由本地 CSS 构成，减少动态效果设置受尊重；输入有明确标签，保留自动填充、键盘验证码刷新、失败保留输入和成功轻提示自动跳转。

已认证工作区的配置和权限菜单在头部提前并行请求，与界面资源加载重叠；数据仅保留本次页面内存，禁止跨账号持久缓存。导航初始化复用这批请求，语言准备、接口权限和失败重试继续生效；请求有超时和错误接管，不重复请求。内存菜单仅延后一轮事件循环以保持实例赋值顺序，取消固定500毫秒等待；CMS工作区不再另设加载遮罩保留时间，保留原淡出动画。登录后后台外观不因此调整。
