## 实现与边界

- `compat/Request.php` 的根域名、后缀解析保留原输入拼写及原版大小写判定；IP、IPv6和单标签保护保持。项目自研 `SitePolicy` 解析手机域名时独立规范化Host，避免大写地区后缀导致错误手机域名跳转。
- `StaticGenerationService::response` 为已生成目录首页提供小写精确 `index.html` 别名：只在该URL没有任何精确记录时，匹配当前语言的规范首页，复用同一份受管发布。保留完整查询参数，且仅限空或 `index.html` 默认首页位置；不产生第二个任务或文件。
- 别名仍通过站点策略、语言、设备、模式、站点/配置签名、公开资格、所有权及文件SHA验证。精确记录无效、空数组或null均不得改取另一记录。没有生成结果时不添加动态首页回退。
- `PublicStaticPublisher::assertWritable` 对无扩展名目录URL检查其 `index.html`，与实际发布路径一致，修复 `/en` 等语言目录无法生成的问题。父级为文件、路径/首页软链接、人工实体仍拒绝，含点非HTML目录未放宽。
- 原版没有固定 `/m/` 或 `/m/index.html` 手机首页入口，本批不注册此路由、不抢占同名栏目/城市/语言。自定义首页和历史 `../index.html` 仍按精确生成记录处理，不扩展默认别名。
