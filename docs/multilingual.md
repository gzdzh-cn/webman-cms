# 多语言维护

## 开关与语言身份

功能地图的搜索下方、当前导航上方只有一个多语言总开关。总开关保存在可信后台配置 `cms_multilingual_enabled`，按全站权限保存；没有修改权限时只读。升级缺少配置时先按原启用语言数量推算，新空站默认关闭。可用 `php webman cms:languages migrate` 预演，`--apply` 仅补缺失开关。

语言管理保留“语言列表／功能配置”。功能配置中的 `web_language_switch` 仅控制前台语言选择器，`language_split` 控制结构联动，两者均不代替总开关。关闭语言分离前核对现有结构关联。

系统主语言为最早建立的语言，只读，不能停用或删除；前台默认语言由语言列表单独设置。后台右上角是唯一编辑语言选择器，允许编辑尚未公开的语言；独立的同步目标和栏目配对不是编辑语言选择器。账号可选语言由其角色范围的并集决定，子角色受父角色和操作者范围限制，旧角色缺少范围时沿用全部语言，超级管理员始终全部。

关闭多语言保留语言、内容、翻译、前台默认选择和公开文件。前台只接受系统主语言，非主语言旧链接返回404，受管HTML和Sitemap也经过服务端判断。后台编辑固定主语言，翻译和管理仍按权限开放；非主语言生成暂停，重新开启后才继续校验任务。没有主语言授权的账号不能通过关停获得主语言权限。

切换语言前检查所有页签的未保存表单和弹窗，确认后退出旧记录编辑，按语言隔离页面记忆，并通知其他窗口。每次业务POST携带当前编辑语言及上下文修订；语言已切换、角色范围变化或旧窗口提交会被服务端拒绝。旧Cookie不能覆盖编辑语言，批量ID和关联ID也核验实际语言。

独立打开的编辑窗口同样监听输入和选择变化，收到其他窗口的语言变更后先确认。没有独立语言字段的附件按所属文档隔离。导航位置及无栏目归属的外链为共享数据，写操作要求具备全部受影响语言范围；跨语言自定义变量、产品参数和结构联动也核对完整影响范围。复制栏目名称使用当前值SHA校验的“待翻译”标记，明确改名后解除标记。

## 新增语言

从系统主语言初始化白名单配置、栏目和关联、空单页、模型字段绑定、表单字段、广告位置、友链分组及产品参数定义。本地基础词库与源语言缺译回退可用，实际译文不复制成“已翻译”。不复制文章、产品、专题正文、广告、友链、留言记录、密钥或全站身份配置。新语言默认不公开，事务失败回滚；相同输入的创建重试不会再创建一次。

复制结构和同步文档的待译信息保存在持久状态，不依赖runtime。内容翻译由编辑者维护，本功能不自动翻译文章，也不把主语言文章当作目标语言文章显示。

## 内容同步

同步源始终为系统主语言，与前台默认和后台当前编辑语言无关。只处理已建立有效栏目关联的企业内容，缺少关联列为跳过并给出原因。

- 同步新文档：只追加未同步记录，不覆盖译文、已有单页正文，不传播源修改和删除。
- 全部同步：先展示完整新增、删除、单页覆盖及跳过清单；只替换有效关联栏目中的支持内容。范围内人工新增文档同样列入删除预览，回收站、会员稿、交易及无关联栏目不删除。
- 配置、广告、友链与语言变量不随文档同步修改。

预览令牌绑定操作者、站点、模式、数据和关联指纹。执行前重新核对，数据、真实ID映射和完成记录在同一连接事务提交；非事务表或不安全引用在预览阶段拒绝。失败可用原任务恢复执行，已完成任务不会重做。失败消息不会输出原SQL；实际异常仅保存在私有日志和回执。

完整同步保存目标前镜像，恢复前核对同步后状态，任何后续目标人工修改都会阻止自动回退。当前恢复保护采用整个目标内容快照，故同步范围外的后续目标编辑也可能要求人工核对；宁可停止，不覆盖新编辑。管理页面可查询自己的任务，接口恢复沿用原reset授权。

## 本地语言包

语言列表各行提供“本地语言包”入口，传入明确的操作目标语言；总开关关闭时仍能维护各语言译文，后台编辑语言继续固定主语言。页面查询、导出和刷新保留目标，并重新校验语言范围。

“本地语言包”与内容同步独立，不检查、下载或同步官方语言包。JSON格式、差异导入、覆盖优先级和限制详见 [语言包格式](language-pack-format.md)。数据库实际值优先，包括明确保存的空值；目标本地基础值其次，再回退系统主语言数据库及基础值。回退显示“待翻译”，无任何定义时返回兼容空值并显示未定义。

JSON导入只补缺失，不覆盖人工译文；先展示差异，再确认绑定文件与数据库指纹。已有值只能通过明确的单项编辑改变。不执行上传PHP，外贸助手词库保持独立。

## 缓存与命令

词库缓存位于 `runtime/cms/languages`，派生JS位于 `runtime/cache/assets`。删除后按数据库和私有JSON自动重建，原主题、上传和已有HTML不修改。缓存键含站点、语言、模板模式及词库修订；静态生成和Sitemap签名也含语言策略和词库修订。

```sh
php webman cms:languages status
php webman cms:languages migrate
php webman cms:languages migrate --apply
php webman cms:languages rebuild
php webman cms:languages rebuild --apply
```

`rebuild`无`--apply`只读预演；所有操作均本地执行，不依赖Node或联网。完整runtime清理仍遵循“停全部worker→删除runtime→重启”，会话和日志不保留。

## 数据库与回退

复用语言、配置、词库、关联、复制日志及CMS持久状态表，无新增业务表。翻译定义/待译、角色范围、预检和恢复回执使用命名空间状态记录。原账号、权限ID、controller身份和角色规则字符串保持。安装器为新站建立可信总开关，不把导入SQL当作可信后台配置。

发布前在项目外保存代码、资源、数据库快照和受保护文件SHA。代码回退需停worker，成组恢复本批代码、资源清单和配套包；不要覆盖新上传、模板、生成HTML或业务内容。新开关可保留作惰性配置；回退语言业务状态前须核对发布后的人工变更，不能直接将整库旧备份覆盖运行站。

## 顶栏和同步窗口细化（2026-11-08）

点击顶栏整个编辑语言按钮展开可见菜单；语言公开状态与后台可编辑范围仍独立。保存、上传或任务未完成时不可切换语言。两种内容同步均使用带独立正文滚动和底部操作的任务窗口，全部同步必须核对完整清单并二次确认。未执行开发库内容同步。见[验收记录](language-city-ui-acceptance.md)。
