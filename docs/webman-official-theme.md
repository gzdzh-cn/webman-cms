# Webman 官方默认企业主题

`template/webman-default` 是本项目维护的原生企业官网主题，使用 `{webman:*}` 和 `$webman`，提供 PC/mobile 对应模板。后台显示“Webman 官方默认模板”。原 `template/default` 在后台显示“EyouCMS 默认模板”，其 HTML、CSS、JS、图片及配置字节保持不变。

## 页面与内容

主导航、关于栏目、产品及新闻入口从栏目数据读取，不依赖现有站点ID。首页包含品牌首屏、服务方向、产品卡片、关于企业、新闻和联系入口；列表、详情、单页、联系、搜索和留言采用统一视觉。图库、下载、视频、招聘、专题及TAG保留现有对应页名和模型入口。全部样式、交互和插画位于主题内，无外部CDN依赖。

PC和手机共享 `assets/site.css`、`assets/site.js` 及本地SVG插画；不同终端保留完整的模板入口。导航支持键盘、移动端展开、子栏目切换；搜索使用现有搜索标签，留言使用实际表单字段与提交协议。

## 初始化和维护

新装可勾选“导入初始化数据”，默认关闭；不勾选为完整空站。演示内容可在文章管理、栏目管理和基本设置中正常编辑。产品仍是展示内容，不包含商城和会员业务。导入原站SQL时禁止混入演示内容。详细字段、重试及删表边界见[安装说明](installation.md)。

模板列表按实际标签检测模式；Webman站点遇到EyouCMS主题显示“当前为 Webman 模式，不支持 EyouCMS 模板”，并继续禁止启用。不完整但语法模式正确的主题仍按既有规则允许启用，访问缺页时显示配置的错误页。

本轮仅完善原生默认主题、安装示例与后台显示，不据此关闭未完成的原版标签严格兼容任务。
