# Redis 缓存模式验收（2026-11-09）

## 实现范围

三种模式及后台保存、CLI切换共用策略；Redis连接采用PHP扩展、私有配置和现行环境优先级。统一存储接入数据、前后台编译、生成编译、语言字典和JS。签名校验、白名单、内存执行及前台依赖检查保留。数据库代际控制缓存及会话失效，Webman仍拥有会话传输和序列化。

Redis缓存失败使用数据库与请求内存，且请求状态不随CMS渲染上下文替换而丢失。成功读取的编译字节在请求内固定。会话读失败明确503；写/注销失败还轮换会话代际。响应发送前保存会话，失败时撤销待发会话Cookie并返回503。没有文件回退。故障警告按worker限频。

后台仍强制编译，不恢复旧后台缓存复用。文件缓存没有显式TTL时上限一天，过期读取及抽样GC回收旧文件。CLI清理范围收窄，保留日志、控制文件、锁及其他状态。
