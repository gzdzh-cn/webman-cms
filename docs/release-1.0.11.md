# webman-cms 1.0.11

- 本版用于验证已部署 1.0.10 站点从 Gitee 检测、下载并执行在线升级。
- 继续使用 Gitee 正式发行版作为升级中心，GitHub 同步发布相同升级包。
- 提供包含锁定依赖的源码运行包，以及 Linux x86_64、macOS ARM64 标准二进制升级包。
- 运行代码及后台资源沿用 1.0.10，本版仅提升 CMS 版本和构建身份，不包含新的业务功能或数据库结构变更。

适用标准源码与仅内嵌系统资源的标准二进制。站点配置、主题、上传、生成 HTML、安装资料及数据库数据不进入升级包。内嵌站点配置或主题的定制二进制需要专用包。

已部署 1.0.10 的站点可在后台“检查更新”查看本版，由超级管理员手动启动升级。1.0.8 的首次 Gitee 切源需要正常部署 1.0.10。正式发布后的升级切换结果以实际任务回执为准。
