# 部署字段及环境变量

字段统一定义于 app/cms/config/ConfigSchema.php。外置配置只选 config.yaml、config/config.yaml、config/manifest/config.yaml 中第一份；本地 .env > 进程环境 > 所选 YAML > 默认。内置 YAML 完全固定，忽略全部外置部署参数。配置写入沿用启动时选中文件；内置配置只读。

实体目录固定相对源码入口或二进制所在目录：config、public/admin-assets、template、uploads、public/html、install、runtime。不再支持 paths 区段及原 CMS_*_DIR / CMS_SITE_ROOT 目录环境变量；旧 paths 区段须删除。build 路径仍可配置，相对入口解析。build 两个列表均支持 YAML 行内/分行，环境列表用 JSON 数组。完整例子见 config/manifest/config.example.yaml。
