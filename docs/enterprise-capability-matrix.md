## 五种状态的含义

| 状态 | 判定 |
| --- | --- |
| 已实现 | 已有可用基础能力及相应既有证据；只表示表中明确的窄范围，不代表全部EyouCMS分支或本轮候选已发布。 |
| 部分实现 | 主流程存在，但仍有明确代码、语义或外部能力缺口，不能按完整原版等价交付。 |
| 未实现 | 未找到相应可用能力或完整实现；后续是否纳入需单独确定，不能以隐藏菜单代替完成。 |
| 待验收 | 本轮已有候选实现及所列有限证据，但发布、实际浏览器、受影响权限/接口或指定输入证据未齐。缺验收不能冒充缺代码，也不能直接关闭任务。 |
| 既定不做 | 已批准企业官网边界明确排除，或按已确认方案主动取消的能力。数据库保留必要结构不代表提供相应业务。 |
